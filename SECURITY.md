# Security policy

## Supported version

The latest commit on `main` is supported. Older snapshots do not receive
separate security backports.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/edcadet10/write-goal/security/advisories/new).
Do not disclose a suspected vulnerability in an issue, Discussion, or pull
request.

Useful reports include a minimal reproduction, affected commit, realistic
impact, and any suggested mitigation. Use fictional or redacted inputs; do not
include credentials, private prompts, or proprietary workspace data.

Relevant reports include unexpected installer writes, unsafe permission or tool
behavior, and instruction patterns that could cause unauthorized actions.
